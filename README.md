# Campus Krishi

A campus farming storefront — browse produce, cart, and checkout.

## Stack

- [Next.js](https://nextjs.org) (App Router) + React + TypeScript
- Supabase
- Tailwind + Framer Motion

## Structure

```
app/
  cart/
  checkout/
```

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
```

## Status

Early / actively developed.
